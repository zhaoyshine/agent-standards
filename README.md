# Agent Standards

Iron rules for AI coding agents: communication density, dev workflow,
testing, comments & docs, commit/PR discipline, and hard red lines.
Content is in Chinese; see `standards.md`.

## Usage

Reference `standards.md` from your project's `AGENTS.md`:

```
@/absolute/path/to/agent-standards/standards.md
```

Or copy `standards.md` into your project root and merge it into your
`AGENTS.md`.
